# Tierney Dynamics blog comments

Public [GitHub Discussions](https://docs.github.com/en/discussions) repository used by [giscus](https://giscus.app) for comments on [tierneydynamics.com](https://tierneydynamics.com) blog posts.

- One discussion per blog post (pathname mapping)
- Category: **Announcements** (only maintainers / giscus create threads)
- Moderate comments here or on the website embed

Do not store site source code in this repository.
